FAQ

Frequently Asked Questions

How does tool calling work?

Actionpackd compiles OpenAPI specs and RPC definitions into JSON function schemas. The execution engine runs tool calls with sub-100ms latency.

Can I connect my WhatsApp Business account?

Yes, connect Meta WhatsApp Business API in 2 minutes with automatic template management and webhook routing.

Is data encrypted and compliant?

All data is encrypted in transit (TLS 1.3) and at rest (AES-256). Dedicated VPC instances available for enterprise.

Can I self-host Actionpackd agents?

Yes, run the Actionpackd daemon in Docker, Kubernetes, or edge runtimes via our open CLI.
